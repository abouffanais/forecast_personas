Libro de remuneraciones (último mes cerrado)

Carga siempre el libro del último mes cerrado. Se usa como línea base de dotación para proyectar Remuneraciones, Horas Extras, Gratificaciones y las cargas patronales adicionales. Al indicar qué mes representa, esa info se considera real/cerrada y el resto del sistema (pestaña 1 y 4) se actualiza para proyectar desde el mes siguiente.

Mapeo de columnas usado — Remuneraciones: Sueldo base + Extras fijos (calculados como el % indicado arriba sobre el sueldo base de cada trabajador, no se suman columnas individuales del libro). Horas Extras: columna Horas Extras. Gratificaciones: A/Gratificación + A/Gratificación líquida + Gratificación mensual. Si tu libro usa otros nombres de columnas, revisa que los encabezados coincidan (no distingue mayúsculas/tildes).

Ajuste de gratificación legal (devengo vs. anticipo del libro)

El libro de remuneraciones solo trae el anticipo mensual de gratificación (columnas A/Gratificación, A/Gratificación líquida, Gratificación mensual). Como el pago real se liquida cada enero del año siguiente, el gasto contable mensual completo es mayor: anticipo del libro + un excedente fijo para llegar al devengo anual/12.

-
Devengo mensual objetivo (anual/12)
-
Anticipo según libro cargado
-
Excedente fijo aplicado cada mes

El excedente se calcula una sola vez (objetivo mensual menos el anticipo del libro cargado) y se suma cada mes proyectado de Gratificaciones, además del anticipo que varía con altas/bajas.

Nuevos ingresos (altas) proyectados

Cada ingreso se prorratea automáticamente desde su fecha de ingreso (base 30 días) y se suma a la dotación a partir de ese mes.

Desvinculaciones (bajas) proyectadas

Selecciona a la persona desde el libro cargado (autocompleta sueldo y bases imponibles) o ingrésala manualmente. El mes de salida se prorratea y se remueve por completo desde el mes siguiente.

Cálculo de indemnización sugerido (editable manualmente en la columna "Monto indemnización"): si el tipo de salida es "Despido", se sugiere 1 sueldo base por año de servicio (tope 11 años) según años calculados entre fecha de ingreso y fecha de salida, más 1 sueldo si no hay aviso previo. Para "Renuncia" o "Mutuo acuerdo" se sugiere solo el pago de vacaciones proporcionales que indiques. Ajusta libremente el monto final.

Ventas mensuales 2026

Las ventas reales (Ene–mes cerrado) se usan para calcular la tasa histórica de los conceptos variables (Comisiones, Bonos y premios). Las ventas proyectadas alimentan el forecast desde el mes de inicio de proyección.

Mes desde el cual proyectar

Los meses anteriores a este se muestran con su valor REAL ingresado en las tablas. Desde este mes (incluido) en adelante, todos los valores se calculan con el motor de forecast.

Cargas adicionales patronales (sobre remuneraciones)

Tasas legales referenciales en Chile, editables. Se aplican sobre las bases imponibles del libro de remuneraciones ajustadas por altas/bajas.

Método de proyección por cuenta (conceptos fijos no asociados a dotación)

Aplica a cuentas Fijas que no son Remuneraciones/Horas Extras/Gratificaciones (las cuales se calculan vía dotación) ni Comisiones/Bonos (las cuales usan razón sobre ventas).

Gastos extras manuales por cuenta

Agrega montos adicionales puntuales (ej. proyectos, gastos no recurrentes) que se sumarán a la proyección de la cuenta seleccionada en la pestaña Forecast. Los meses que ya están cerrados como reales (según el selector "Proyectar desde" de la pestaña 4) quedan bloqueados: solo puedes ingresar montos en los meses de proyección hacia adelante.

Estos montos se suman por cuenta y por mes a lo que calcule el motor de forecast (dotación, ventas o tendencia, según corresponda) — no reemplazan el cálculo, se agregan encima.

Sincronización compartida

Si se configuró un servidor compartido (Google Apps Script), los datos se guardan ahí automáticamente y cualquier persona que abra este link ve la misma información.

Exportar / respaldar datos

Si NO hay servidor compartido configurado, los datos se guardan solo en este navegador (localStorage) y no se comparten al enviar el link. Usa el respaldo JSON para moverlos a otro computador o compartirlos manualmente.
